## Overview

FabFilter Pro-MB is a precise multiband dynamics processor with variable crossover frequencies, transparent compression, dynamic EQ mode, and individual band soloing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FabFilter Pro-MB** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiband** | Up to 6 frequency bands with variable crossover frequencies |
| **Dynamic EQ** | Per-band can operate as a dynamic EQ band for transparent processing |
| **Band Solo** | Solo individual bands for precise monitoring and adjustment |
| **Stereo/M/S** | Independent stereo, mid, and side processing per band |
